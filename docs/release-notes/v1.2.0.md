# Codex Monitor Mobile 1.2.0 (Build 2)

Codex Monitor Mobile 1.2.0 is the first functional iPhone release. It adds an
independent small WidgetKit widget and connects it to the user's Codex account
without relying on the Mac app.

- Adds the approved small iPhone widget with weekly quota remaining and reset
  time.
- Adds an interactive refresh button that does not open the container app.
- Uses OpenAI's Codex device-code authorization flow in the system browser.
- Reads the weekly quota window from the same ChatGPT backend path used by the
  official open-source Codex client.
- Stores OAuth credentials only in the iOS Keychain shared by the app and its
  widget extension.
- Stores only a non-sensitive quota snapshot in the App Group for offline
  fallback.
- Retries temporary connection loss caused by returning from Safari after
  authorization.
- Refreshes automatically on the WidgetKit timeline and preserves the last
  successful value when the network is unavailable.

Verified on a physical iPhone with automatic development signing. Device,
account, certificate, authorization-code, and token values are intentionally
excluded from source files and release records.
