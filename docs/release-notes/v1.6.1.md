# Codex Monitor 1.6.1

## 简体中文

- Gemini 周额度和 5 小时额度优先从运行中的 Antigravity 或 Gemini for Mac 读取。两者均未返回额度时，Monitor 会尝试 Gemini for Mac 随附的 `agy` CLI（1.1.11 或更高版本）。后台查询需要有效的本机 Google 登录，关闭两个图形界面后也可使用。
- 通用安装包版本为 1.6.1（Build 62），支持 macOS 13 及以上、Apple Silicon 和 Intel。

## English

- Monitor checks running Antigravity and Gemini for Mac clients for weekly and 5-hour Gemini quota. If neither returns quota, it tries the `agy` CLI bundled with Gemini for Mac (1.1.11 or later). Background reads require a valid local Google sign-in and can run with both desktop apps closed.
- The universal 1.6.1 installer (Build 62) supports Apple Silicon and Intel on macOS 13 or later.
