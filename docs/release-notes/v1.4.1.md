# Codex Monitor 1.4.1

First consolidated open-source release of the Codex Monitor dashboard.

## Included

- Native macOS menu bar application with one-minute local usage refresh.
- Medium and large macOS widgets, including a seven-day token chart.
- Independent iPhone app and interactive small widget source.
- Tested `NRF_EPD_8042` 4.2-inch black/white/red BLE transport.
- Final 400 × 300 pixel-aligned EPD layout and deterministic renderer.
- Hourly EPD checks, immediate cross-day checks, stable frame deduplication,
  short BLE connections, and one retry on connection/write failure.
- Bilingual reproduction and privacy documentation.

## Distribution

The GitHub Release contains an ad-hoc signed universal macOS DMG and SHA-256
checksum. iPhone installation requires a local build with the user's own Apple
Development team. No account credentials or device identifiers are included.
