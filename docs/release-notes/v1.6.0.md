# Codex Monitor 1.6.0

## 简体中文

- 菜单栏把 Codex 周额度、Gemini 周额度和 Gemini 5 小时额度集中到三条进度条。蓝色进度条下方显示重置倒计时。移除菜单里的近七日 Token 图，减少面板高度。
- ChatGPT 左侧的外观徽章沿用原有宽度。绿色内圈对应 Gemini 周额度，蓝色外圈对应 Gemini 5 小时额度。下方显示 Codex 剩余百分比，悬停可查看两档 Gemini 的额度和重置时间。
- Gemini 可复用已登录的官方客户端。Antigravity 关闭时，Monitor 使用 Gemini for Mac 自带的 `agy`（1.1.11 或更高版本）在后台执行只读额度查询，无需打开两个图形界面。首次读取需要本机已有有效登录。
- macOS 13+ 通用版，支持 Apple Silicon 和 Intel。已安装外观增强的用户可在 Monitor 中选择 **安装 / 更新 / 修复** 加载新版徽章。

## English

- The menu groups Codex weekly, Gemini weekly and Gemini 5-hour quota in three progress bars. A countdown appears below the blue 5-hour bar. The seven-day Token chart has been removed from the menu.
- The ChatGPT sidebar badge keeps its original width. The green inner ring represents Gemini weekly quota and the blue outer ring represents the 5-hour quota. Codex remaining quota appears below the rings. Hover to see both Gemini values and their reset times.
- Gemini uses your existing Google sign-in. With both desktop apps closed, Monitor can query quota in the background through the `agy` CLI bundled with Gemini for Mac (1.1.11 or later). This requires a valid local sign-in.
- The universal build supports Apple Silicon and Intel on macOS 13 or later. If you already use the appearance helper, choose **Install / Update / Repair** in Monitor to load the new badge.
