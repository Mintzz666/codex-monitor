# Codex Monitor 1.4.7 (Build 44)

- Pass active macOS proxy settings to the Codex subprocess, including when
  launched from Finder or at login. Respect explicit environment overrides and
  keep localhost traffic local. Remove automatic ChatGPT/direct bypass retries.
- Divide a 45-second refresh budget between two attempts so a slow first
  attempt cannot starve the retry. Preserve older stdio CLI compatibility.
- Skip reset-credit detail requests during background quota polling; retry
  without that parameter when an older CLI rejects it. Optional token activity
  cannot invalidate an already successful quota response.
- Retry failures after 15, 30, then 60 seconds and refresh on network recovery.
  Authentication errors stop promptly. Existing cached quota data stays visible
  when a refresh fails, with its original update time.

Clash rules, subscriptions, node selection, TUN, and system proxy preferences
are unchanged by the app. See [architecture and privacy](../architecture-and-privacy.md).
