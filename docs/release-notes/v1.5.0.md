# Codex Monitor 1.5.0

## 中文

- 加入中英文重置倒计时，每分钟更新；到期后显示“等待重置”。
- 正式整合登录恢复修复：识别先于助手启动、尚未操作的恢复窗口；慢启动等待窗口延长至一分钟；后台恢复不抢焦点，已在使用的窗口跳过。
- 外观管理页单独显示登录启动助手状态，并随语言切换窗口标题。
- 健康检查结果短时复用：正常 30 秒、异常 5 秒；“立即检查”强制更新。检查进程增加时限，避免界面一直等待。
- 保留运行包白名单，去掉共享额度入口未调用的旧网络适配代码。Monitor 继续作为唯一额度采集入口，外观复用经过账号和时效核验的本机快照。
- 更新流程先核验应用及标识符；替换后签名或启动失败时恢复旧版。账号、语言、登录启动选择和小组件标识保留。
- 版本统一为 **1.5.0 / Build 50**，构建、DMG、CI 和 tag 对齐；发布前检查 DMG 内应用、双架构、签名、资源清单与构建路径隐私。

发布包仅包含运行、诊断和许可文件；源码、测试与历史回退材料留在仓库。磁盘体积变化以本次发布审查中的实测为准，不据此推断 CPU、内存或能耗收益。重启后的长期恢复和第三方客户端后续更新仍需实际观察。

## English

- Add an English/Simplified Chinese reset countdown, updated each minute, with an awaiting-reset state.
- Ship the login-recovery fixes for untouched restored or slow-starting windows. Background restoration stays hidden; interactive clients are skipped.
- Show login-watcher health separately and localize the appearance window title.
- Reuse healthy status checks for 30 seconds and attention states for 5 seconds. **Check now** bypasses the cache; helper execution has a deadline.
- Keep runtime-only packaging and remove unused legacy networking from the shared-quota entry point. Monitor remains the quota collector; the appearance agent accepts only fresh, account-matched local snapshots.
- Verify app/widget identities before replacement and restore the previous app after a failed installed signature check or launch. Keep account state and existing preferences.
- Align builds, DMGs, CI and tags at **1.5.0 / Build 50**. Verify the app inside the DMG, universal architectures, signatures, the Badge allowlist and build-path privacy.

Source, tests and historical rollback material remain in the repository. Disk-size measurements do not establish CPU, memory or energy savings. Real reboot recovery and compatibility with future client updates remain separate checks.
