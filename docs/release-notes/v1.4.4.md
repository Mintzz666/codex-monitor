# Codex Monitor 1.4.4 (Build 40)

Codex Monitor now focuses on the Mac menu bar, desktop widgets, and the existing
NRF_EPD_8042 display.

- Remember the launch-at-login choice across application restarts, including
  subsequent changes made in System Settings.
- Make the menu panel scrollable and fit its height to the current display.
- Add manual refresh with Command-R and refresh stale usage after Mac wake.
- Update the menu bar tooltip immediately when language or refresh status changes;
  dim the cached percentage after a failed refresh.
- Remove the retired iPhone app, mobile widget, iOS Xcode project, and iOS CI job.
- Reuse incremental Xcode build output and allow optional local menu artwork.
- Add a local install command that preserves the installed bundle identifiers
  and keeps the previous application as a rollback copy.

The desktop cleanup makes no changes to the currently working EPD renderer,
Bluetooth transport, synchronization schedule, or stored device settings. The
source includes the already established local 1.4.3 Bluetooth reliability fixes.

Mobile source remains available in earlier Git history. macOS still requires
full Xcode to build the application and its desktop widget extension.
