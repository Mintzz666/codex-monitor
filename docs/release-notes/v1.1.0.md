# Codex Monitor 1.1.0

Codex Monitor 1.1.0 preserves the approved macOS V1 interface and adds the
first hardware-expansion boundary for a future 4.2-inch electronic-paper
display.

- Adds the approved 400 × 300 black/white/red EPD page design.
- Includes a compact Monday-to-Sunday calendar with inverse highlighting for
  today, current time, weekly quota details, and daily Token chart.
- Produces two validated 15,000-byte 1-bit color planes.
- Adds firmware-neutral `EPDFrame` and `EPDTransport` interfaces.
- Deliberately leaves GATT UUIDs and packet framing undefined until the
  physical device or its control source is available.
