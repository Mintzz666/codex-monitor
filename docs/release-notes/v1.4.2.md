# Codex Monitor 1.4.2 (build 38)

Frozen working baseline for the macOS, iPhone widget, and 4.2-inch Bluetooth
e-paper dashboard. This version was hardware-verified on 2026-09-01.

## Included

- Native macOS menu bar dashboard and WidgetKit widgets.
- Independent iPhone app and small interactive widget source.
- Final 400 × 300 black/white/red e-paper layout.
- Live seven-day usage data including the current day.
- Hourly e-paper checks, immediate cross-day checks, frame deduplication, and
  short-lived Bluetooth connections.

## Verified e-paper profile

- Retail model: ZKONG ZKC42V, 4.2-inch ESL-BWR.
- Bluetooth advertisement: `NRF_EPD_8042`.
- Firmware value: `0x1B`.
- Display controller profile: SSD1619, 400 × 300 black/white/red.

The reliable connection sequence is: start a fresh name-based scan, connect
directly from the new advertisement, discover the EPD service and
characteristic, read device information, send both image planes, issue the
refresh command, and then disconnect. Some compatible firmware intentionally
drops the BLE link while accepting the final refresh command; after all image
packets have been acknowledged, that disconnect is recorded as a successful
refresh. Disconnects during image transfer remain failures.

## Operating notes

- Only one BLE client can control the display at a time. Disconnect the browser
  controller before syncing from Codex Monitor.
- Cached device information is shown only as historical information and is not
  treated as a live connection.
- Identical frames are skipped to reduce power consumption and radio traffic.
- No personal account identifiers, local paths, tokens, device addresses, Apple
  signing identifiers, or credentials are part of this release record.
