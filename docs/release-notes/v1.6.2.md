# Codex Monitor 1.6.2

## 简体中文

- ChatGPT Plus 用户可正常查看 Codex 额度。Gemini 功能可选，菜单只显示实际读取到的 Gemini 额度条。
- 修复新建对话或自动更新标题时，ChatGPT 侧栏的 Token 色块短暂消失的问题。
- macOS 通用安装包支持 macOS 13 及以上、Apple Silicon 和 Intel。

## English

- ChatGPT Plus users can view their Codex quota with or without Gemini. The menu shows only the Gemini quota windows it can read.
- Keep the ChatGPT sidebar Token marker in place when a new conversation's title loads or changes.
- The universal installer supports macOS 13 or later on Apple Silicon and Intel.
