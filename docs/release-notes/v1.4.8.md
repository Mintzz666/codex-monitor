# Codex Monitor 1.4.8 (Build 45)

- Publish one authenticated quota snapshot for Monitor, its existing widget
  bridge, and the customized sidebar Badge. The Badge reads the loopback
  snapshot and no longer starts a second Codex quota process.
- Verify the active Codex account before publishing and reject responses from
  another account. Shared data contains an account fingerprint and quota fields;
  account identifiers and credentials are not published.
- Preserve the original successful-fetch time. The Badge checks account and
  freshness locally, becomes unavailable when the source expires, and resumes
  when Monitor publishes fresh data. Node/subscription changes retain the
  existing dynamic proxy and bounded retry behavior.
- Keep backward compatibility with older widget snapshots. The separate Widget
  fallback cache is unchanged; this release's account-switch invalidation covers
  Monitor and the sidebar Badge.

Monitor is the only quota collector. When it is explicitly quit, the Badge
waits for Monitor to return instead of starting an independent network reader.
